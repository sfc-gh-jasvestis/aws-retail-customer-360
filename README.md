# Customer 360 & Loyalty — Reference Architecture Demo
### Snowflake + Amazon Bedrock + SES + QuickSight | Retail/CPG

> An end-to-end customer intelligence platform across 12 APJ markets — from unified profiles to ML-powered churn prediction, with personalized re-engagement messages generated by Amazon Bedrock and automated emails via SES.

## What It Does

| Capability | Technology | Detail |
|---|---|---|
| Customer 360 | Dynamic Tables | Unified profile: spend, frequency, recency, tier, loyalty, sentiment |
| Segmentation | Cortex AI_CLASSIFY + rules | RFM-based segments: Champions, Loyal, At Risk, Hibernating |
| Churn Prediction | Snowflake ML CLASSIFICATION | Multi-class: ACTIVE / AT_RISK / CHURNED (284 at-risk, 7 churned) |
| Revenue Forecast | Snowflake ML FORECAST | 30-day revenue prediction by channel |
| Personalization | Amazon Bedrock (Claude) | Generates personalized next-best-action per customer |
| Automated Action | Amazon SES via EAI | Sends re-engagement emails when churn risk exceeds threshold |
| Insight Search | Cortex Search | Semantic search over 15K feedback + support tickets |
| Analyst UI | Streamlit in Snowflake | 5-tab Customer Hub |
| Executive BI | Amazon QuickSight + Amazon Q | CLV segments, churn dashboard, campaign ROI |
| NL Queries | Semantic View + Cortex Agent | "How many Gold customers have churn risk?" |

## Two Personas

| Persona | Tool | What they see |
|---|---|---|
| **Marketing Analyst** | Streamlit in Snowflake | Customer profiles, segments, churn risk, personalized NBA, campaign analysis |
| **CMO** | Amazon QuickSight + Amazon Q | CLV trends, segment health, campaign ROI, NLP: "Which segment is churning fastest?" |

## Key AWS Differentiators

This demo uniquely showcases the **detect → personalize → act** loop:
1. Snowflake ML detects churn risk
2. Amazon Bedrock generates a personalized offer
3. Amazon SES sends the re-engagement email
4. All triggered by a Snowflake ALERT — no Lambda, no cron

No S3 — first-party customer data stays in Snowflake's governance perimeter.

## Quick Start

### Prerequisites
- Snowflake account with ACCOUNTADMIN
- `snow` CLI configured
- AWS CLI with Bedrock, SES, QuickSight access (us-west-2)

### Build
Run SQL files in order (00 → 08), then deploy Streamlit and QuickSight:
```bash
cd streamlit/deploy && snow streamlit deploy --replace --connection <CONNECTION>
bash quicksight/deploy.sh
```

### Update Bedrock Credentials (optional — Cortex AI works without Bedrock)
```sql
ALTER SECRET RETAIL_CUSTOMER_360.AI.BEDROCK_SECRET
    SET SECRET_STRING = '{"aws_access_key_id":"AKIA...","aws_secret_access_key":"..."}';
```

### Health Check
```sql
SELECT
    (SELECT COUNT(*) FROM RETAIL_CUSTOMER_360.RAW.CUSTOMERS) AS customers,
    (SELECT COUNT(*) FROM RETAIL_CUSTOMER_360.RAW.TRANSACTIONS) AS transactions,
    (SELECT COUNT(*) FROM RETAIL_CUSTOMER_360.CURATED.CUSTOMER_PROFILE) AS profiles,
    (SELECT COUNT(*) FROM RETAIL_CUSTOMER_360.ML.CHURN_PREDICTIONS) AS predictions;
```
